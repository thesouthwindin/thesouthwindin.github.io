Black Light Content OS

Black Light Content OS is a private editorial tool used by one creator to plan and write videos for the Black Light YouTube channel, a Malayalam film-analysis channel.

The tool connects to YouTube with read-only access to the creator's own channel so it can read video statistics and analytics. It cannot upload, edit or delete anything on YouTube.

It is not offered to the public and has no sign-up. Its only user is the channel owner.

This app uses YouTube API Services.
